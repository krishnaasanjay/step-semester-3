# Week 1 — Practice Problems

5 problems solved in Java, each as a single self-contained `.java` file under `Practice Problems/`.

| # | Title | Key Concepts |
|---|-------|---------------|
| 1 | Rock-Paper-Scissors Game | Conditional logic, loops, arrays, formatted output, percentage calculation |
| 2 | Palindrome Checker (3 Approaches) | Loops, recursion, array manipulation, string comparison |
| 3 | BMI Calculator for a Team | Parallel arrays, arithmetic operations, conditional logic, tabular output |
| 4 | First Non-Repeating Character | Character frequency counting, array-based counting, early-exit scanning |
| 5 | Reverse Customer Name | String traversal, character array manipulation, string reconstruction |
